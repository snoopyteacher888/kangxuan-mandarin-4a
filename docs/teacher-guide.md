# 國語四上學習樂園：老師使用說明

這份說明分成兩部分：**第一次上線前的設定**（只要做一次），以及**平常怎麼使用**。
遇到看不懂的步驟，直接把畫面截圖給 Claude，Claude 會陪您一步步做。

---

## 第一部分：第一次上線前的設定

### 步驟 1：GitHub 網站（已有帳號，建立新儲存庫）
> 三年級網站已經有 GitHub 帳號，這一步只要在同一個帳號建立新的儲存庫 `kangxuan-mandarin-4a`（Public），並在 Settings → Pages 選 main 分支。以下是第一次申請帳號的步驟，供參考。

1. 用電腦打開 https://github.com/signup 。
2. 輸入 Email、設定密碼、取一個帳號名稱（英文和數字，例如 `vivian-sped`）。這個名稱會出現在網址裡。
3. 完成 Email 驗證。
4. 告訴 Claude 您的帳號名稱。Claude 會說明怎麼把帳號連結到 Claude，然後幫您建立網站。
   網址會像這樣：`https://您的帳號名稱.github.io/kangxuan-mandarin-4a/`

### 步驟 2：建立老師後台（Google 試算表）
1. 打開 https://sheets.google.com ，建立一份**空白試算表**，命名為「國語四上學習紀錄」。**請另外建一份，不要和三年級共用**，因為兩個年級的課次代號（L01～L12）一樣，紀錄會混在一起。
2. 上方選單點「**擴充功能 → Apps Script**」。
3. 把編輯區原本的內容全部刪掉，貼上 Claude 給您的 `Code.gs` 全部內容，按 💾 儲存。
4. 左邊點「⚙️ **專案設定**」，拉到最下面「**指令碼屬性**」→「**新增指令碼屬性**」：
   - 屬性：`TEACHER_PASSWORD`
   - 值：您自己想的**老師後台密碼**（不要告訴學生、家長，也不要告訴 Claude）
   - 按「儲存指令碼屬性」。
5. 右上角「**部署 → 新增部署作業**」：
   - 類型選「**網頁應用程式**」
   - 執行身分：「**我**」
   - 具有存取權的使用者：「**所有人**」
   - 按「部署」。第一次會要求授權，選您的 Google 帳號 →「進階」→「前往（不安全）」→「允許」。
     （這是因為程式是您自己貼的，Google 沒有審核過，屬於正常情況。）
6. 複製「**網頁應用程式網址**」（https://script.google.com/macros/s/……/exec），交給 Claude。這個網址可以給 Claude，它不是密碼。

> 學生的紀錄會出現在試算表的「records」工作表，名冊在「roster」工作表，學生用「🎤 說說看」說的句子在「speech」工作表。請不要手動改欄位名稱。

#### 以後 Claude 更新 Code.gs 時（例如新增「說說看」）
1. 打開試算表 →「擴充功能 → Apps Script」。
2. 把編輯區內容全部刪掉，貼上新的 `Code.gs`（GitHub 上 `backend/Code.gs`），按 💾 儲存。
3. 右上角「**部署 → 管理部署作業**」→ 點右邊的 ✏️（編輯）→「版本」選「**新版本**」→ 按「部署」。
4. 網址不會變，不用再交給 Claude。（不要按「新增部署作業」，那樣網址會變。）

### 步驟 3：加密課文（設定教室密碼）
1. Claude 會把每一課的原稿（例如「`lesson01.plain.json`」）放在您的 Google 雲端硬碟，請先下載到電腦或平板。
2. 打開網站，長按右上角 ⚙️ **2 秒**，答對乘法題，進入「老師設定」→「🔐 加密工具」。
3. 選擇原稿檔，輸入您想的**教室密碼**兩次（至少 6 個字），按「加密並下載」。
4. 會下載一個 `lesson01.enc.js`（每一課一個）。把它放到 Google 雲端交接資料夾，告訴 Claude。
5. **請記住教室密碼**，Claude 不知道這個密碼，忘記了只能重新加密。

### 步驟 4：產生圖片
1. 打開 Claude 給您的「圖片清單」（`image-list.md`）（每一課一份，放在雲端交接資料夾）。
2. 每張把「完整提示詞」貼給 ChatGPT，下載圖片後**改成清單上的檔名**。
3. 上傳到 GitHub 的 `images/L01/`（依課次），告訴 Claude，Claude 會壓縮並開放該課。
4. 還沒做好的圖片，網站會先用灰色框加文字代替，不影響使用。

### 步驟 5：建立學生名冊
1. 網址後面加上 `#/teacher`（例如 `https://您的帳號.github.io/kangxuan-mandarin-4a/#/teacher`），輸入老師後台密碼。
2. 在「學生名冊」選動物、按「＋ 新增學生」，最後按「儲存名冊」。
3. 動物代號對應哪位學生，請記在**您自己的筆記**裡，網站上不放真實姓名。

## 第二部分：平常怎麼使用

### 在學校（電子白板）
1. 用電子白板打開網站，長按 ⚙️ 2 秒 → 答乘法題 → 「這台裝置是誰在用？」選「**全班**」。
2. 第一次進入課文時輸入教室密碼，之後會記住。
3. 這台電子白板的紀錄會算在「全班」。

### 給家長的任務連結
1. 在老師設定的「**產生任務連結**」選學生、課次、活動，需要的話勾「自動念出題目」。
2. 按「📋 複製連結」，貼到 LINE 傳給家長。
3. 家長第一次打開要輸入**教室密碼**（請另外告訴家長，並提醒「課文有著作權，密碼請勿外流」）。
4. 學生做完後，紀錄會自動送到您的後台。

### 看學生的作答情形
- 打開 `#/teacher`，輸入老師後台密碼。
- 可以依學生、活動、日期篩選，按「看細節」看每一題的作答過程、選錯了哪個選項。
- 「最常錯的題目」可以幫您決定上課要再講解哪一段。
- 登入後 2 小時沒有操作會自動登出；密碼連續輸錯 5 次會鎖住 15 分鐘。

### 課次頁的三區
- 🎯 **本課先完成**：認識生字、學會語詞、生字語詞、短語短句、句型、課文地圖、理解提問。
- ⭐ **加練挑戰**：形近字、生字變成語、修辭小偵探、聽聽看。
- 🔁 **複習與小考**：錯題複習、單元測驗。
- 每張卡都有一句話說明這一關在練什麼，按 🔊 會念出來。

### 分步驟的活動（上課可以直接點要從哪一步開始）
畫面最上面有一排步驟按鈕（✓ 做完、▶ 正在做），點任何一步就從那一步開始。一步做完會自動提示下一步；最後一步做完才給星星。
- **認識生字**：認識生字（一頁 5 張卡，都點過才能下一頁）→ 拖字填空 → 組合字 → 改錯字。
  - 組合字：看「黑＋土＝□」，把組成的字（墨）拖進空格；選項是長得像的字（墨、黑、默、磨）。不說「部件」。
  - 改錯字：先點出句子裡寫錯的字，再選正確的字。
- **學會語詞**：看語詞卡 → 圖片連連看（從圖拉一條線到語詞）→ 選語詞 → 翻牌配對。
- **生字語詞**：翻翻卡（每個生字再學一個課本以外的語詞）→ 拖詞填空 → 意思連連看。
- **生字變成語**：學成語（兩個一組：看成語卡 → 排成語 → 把成語拖到適合的句子上，再換下兩個）→ 看情境選成語 → 連連看。
- **短語短句**：認識短語 → 看圖選疊字 → 看圖說說看。
- **句型**（先選句型）：認識句型 → 前後配對 → 拼句子（關聯詞印好，其他每一塊拖進空格）→ 說後半句 → 自己說一句。
- **課文地圖**：課文架構（魚骨圖；第 2、8、10、11、12 課照課文結構表畫成樹狀圖）→ 人事時地物（只有記敘文、應用文：第 2、3、8～12 課）：先認識人、事、時、地、物，再一個字一題，最後整理成一張表。
- 翻牌配對：圖片卡翻開就念；文字卡翻開不念，按卡上的 🔊 才念。
- 三選一的題目，第二次選錯就「老師教你」。
- **理解提問**：照課本「閱讀理解提問」學習單的分類：提取訊息 → 推論訊息 → 詮釋整合 → 比較評估（這一課沒有的類別就不出現）。「說說你的想法」放在它所屬的那一類。
- 拖拉的題目一定要拖到位置上才算作答；點卡片、句子只會念出來，方便不太會讀的孩子先聽再拖。
- 提示：答錯一次就直接給比較具體的線索（例如排成語會幫忙放好前兩個字、改錯字會框出範圍）；學生自己按 💡 才會先給第一層。

### 錯題複習
- 每個學生各自一份，記在自己的裝置上（全班用的白板記在「全班」）。
- 答錯或用了提示，那一題**馬上**收進這一課的錯題複習，不用等到隔天。
- 在錯題複習裡，連續 2 次第一次就答對，才會從清單拿掉。

### 理解提問
- 「理解提問」照課本的閱讀理解提問順序出題，畫面上的小標是：找答案（提取訊息）→ 動動腦（推論訊息）→ 前後連起來（詮釋整合）→ 我的看法（比較評估）。全部都是選擇題，不用口頭回答；「我的看法」裡的「選選看」有兩個合理的答案，選哪一個都對。
- 課本流程圖（第 61 頁）的內容網站上沒有，那一題請在課堂上帶。

### 🎤 說說看（短語短句、句型）
- 學生按 🎤 說話，電腦把話變成文字、念回來，學生按「✅ 送出」或「🔁 再說一次」。
- 第一次在白板（或家長的電腦）上按 🎤 時，瀏覽器會問「要允許使用麥克風嗎？」，請按「**允許**」。
- 需要網路（Chrome／Edge 會把聲音送去 Google／微軟辨識）。不能用說的時候，畫面會改成「請大人幫忙打字」。
- 系統只檢查句型（例如有沒有說到「只要」和「就」）。句型對了，句子合不合理由您批改。

### 批改學生說的句子
- 打開 `#/teacher` 登入，最上面是「📝 待批改」。
- 每一句旁邊有 🔊 可以聽。按「✅ 合理」學生得到 3 顆星；按「🔁 再試一次」學生會看到「再說一次」按鈕。
- 「老師的話」可以不填；有填的話，學生打開「老師的批改」時，電腦會念給他聽。
- 已批改的句子在下方「已批改」裡，點開可以改。
- 學生回到課次頁，上面會出現「👩‍🏫 老師批改了 N 題」。

### 常見問題
- **沒有聲音／聲音不是台灣口音**：畫面上方會出現黃色提示條，點「怎麼下載？」照步驟下載「中文（台灣）」語音。
- **念錯字（破音字）**：記下是哪一句、哪個字，告訴 Claude 修正。
- **想重新上鎖課文**：老師設定 →「🔒 鎖定課文」。
- **換教室密碼**：用加密工具重新加密一次，交給 Claude 更新。所有裝置都要重新輸入新密碼。
