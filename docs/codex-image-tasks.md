# Codex 生圖指令：用語詞造句圖示＋三張連續提示圖

請依照下面的清單畫圖，畫好後**直接存到指定的路徑**（檔名要一模一樣），再 commit、push。
每一張圖都是單獨一張，不要把三個場景畫在同一張裡。

## 共同規則

- 存檔前把圖縮成指定大小，存成 PNG。
- 畫面中**不要有任何文字、數字、注音**。
- 同一組的三張圖，人物、動物、地點的長相和衣服要一致，看得出是同一個人、同一個地方，只有動作或場景不同。
