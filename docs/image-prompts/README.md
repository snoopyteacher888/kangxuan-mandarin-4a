# 圖片生成指令（給 Codex 或其他生圖工具）

每一課一個檔案：`L01.json`、`L02.json`……。

## 要做的事

1. 打開要做的那一課的 JSON，例如 `L02.json`。
2. `images` 裡的每一個項目都生成**一張**圖片：
   - 用 `prompt` 的整段文字當作提示詞（已經包含統一風格）。
   - 檔名用 `file`（全部小寫英文，例如 `red-bean-soup.png`），存到 `folder` 指定的資料夾（例如 `images/L02/`）。
3. 規格：
   - PNG，正方形 1:1（建議 1024×1024）。
   - 白色背景，兒童繪本風格，單一主體置中。
   - **畫面中不要有任何文字、數字、字母或注音**（招牌、報紙、春聯上也不要有字）。
   - 不要畫任何有版權的卡通人物或品牌商標。
   - 人物是一般的台灣小學生、家人、老師，不要畫真實名人。
4. 已經存在的檔案不要重畫、不要覆蓋。
5. **只新增 `images/LNN/` 裡的圖片**，不要修改其他任何檔案。
6. 全部畫好後 commit，訊息例如：`新增第 2 課圖片（74 張）`。

圖片上傳後，Claude 會再把圖片壓縮成 512px 並開放該課。
